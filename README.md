# Адамант

Проверка защиты компьютера с Windows и своей домашней или офисной сети. Адамант - старинное имя алмаза, «несокрушимый».

Программа работает в своём окне, ставится в один щелчок и ничего не отправляет в интернет.

## Что проверяет

**Этот ПК**
- Открытые порты: какая программа слушает, доступна ли она из сети или только с этого компьютера.
- Брандмауэр, Microsoft Defender (или другой антивирус), SMBv1, удалённый рабочий стол (RDP и NLA), контроль учётных записей (UAC).
- Учётные записи: гость, встроенный администратор, пустые пароли, пароль автовхода в реестре, число администраторов.
- Автозагрузка: список и подозрительные записи (временные папки, скрытые команды PowerShell, загрузка кода из интернета).
- Обновления Windows: когда ставились, не отключены ли.
- BitLocker, Secure Boot, TPM.
- Пароль BIOS/UEFI и порядок загрузки - насколько это видно из Windows. Если прошивка не сообщает о пароле, программа так и пишет и даёт инструкцию.
- Защита от взлома: защита LSA, WDigest, NTLM, целостность памяти, Credential Guard, облачная защита и правила ASR Defender, контролируемый доступ к папкам, SmartScreen, LLMNR/NetBIOS/WPAD, подпись SMB, WinRM, удалённый реестр и помощник, PowerShell 2.0, автозапуск с флешек, макросы Office.
- Физический доступ: подмена специальных возможностей (вход в обход пароля), загрузка с флешки при незашифрованном диске, BitLocker без PIN, автоблокировка, вход после сна, защита от атак через Thunderbolt, неверные пароли, история включений и флешек.
- Готовность к беде: резервные копии, точки восстановления. Устаревшие программы. Открытые сети Wi-Fi. Кто включал камеру и микрофон.
- Расширения браузеров (Chrome, Edge, Яндекс, Brave, Vivaldi, Opera, Firefox): поставленные в обход магазина, навязанные политикой, с доступом ко всем сайтам и к паролям, cookies, переписке. Политики, которые подменяют домашнюю страницу, поиск или прокси.
- Скачанные файлы за 30 дней (только с отметкой Windows «из интернета»): двойное расширение, перевёрнутое имя, сценарии и ярлыки, программы без подписи, образы дисков, документы с макросами. У каждого файла - «Проверить антивирусом», «Показать в папке», «В корзину».

**Индекс защиты** - число от 0 до 100 и «чистота камня» (Тёмный, Мутный, С включениями, Прозрачный, Чистой воды). Критичная находка не даёт индексу подняться выше 49. История ведётся по дням.

**Страж** - запоминает, как устроена система (службы, задачи, автозагрузка, подписки WMI, сертификаты, hosts, DNS, прокси, исключения антивируса, администраторы, порты, порядок загрузки), и при каждой проверке показывает, что изменилось. Ищет следы взлома в журналах Windows за 14 дней. Недельная сводка - «всё спокойно» или что посмотреть. Шкала «Когда пользовались»: строка - день, клетка - час, цвет - самое важное событие часа, число - неверные пароли. На вкладке - Кира в алмазных доспехах, она охраняет.

**Учения** - по кнопке: учебный вирус EICAR, учебный сценарий AMSI, попытка записи в «Документы», «взгляд соседа по сети». Безвредны, всё за собой убирают.

**Приманки для шифровальщиков** - по желанию (по умолчанию выключены): скрытые файлы в «Документах» и на рабочем столе. Если файл изменится - тревога в окне и в трее.

**Пока вас не было** - по желанию (по умолчанию выключено, работает вместе со значком в трее). Когда вы блокируете компьютер (Win+L) или он засыпает, Адамант записывает неверные пароли, разблокировки, входы других учётных записей, запуск программ, подключение флешек и изменения файлов в «Документах», на рабочем столе и в «Загрузках». Когда вернётесь - хронология и кнопка «Это был я». По желанию - фото с камеры того, кто ввёл неверный пароль. Всё хранится только на этом компьютере.

**Защита входа** - мастер «Закрыть вход в обход Windows»: ключ восстановления, разрешение PIN при включении, BitLocker с PIN (через мастер самой Windows), пароль BIOS/UEFI и порядок загрузки. Плюс проверки входа: блокировка после неверных паролей, Ctrl+Alt+Del перед входом, PIN Windows Hello, динамическая блокировка.

**Помощник администратора** - по желанию: одно разрешение Windows при установке, дальше системная задача раз в сутки и сразу после неудачного входа читает то, что видно только администратору. Сама программа прав администратора не получает. Подробно - в SECURITY.md.

**Своя сеть**
- Устройства и открытые службы - только в частных подсетях своих адаптеров (10.x, 172.16-31.x, 192.168.x), не больше 256 адресов на сеть.
- Только обычные подключения к 28 портам и заголовок веб-страницы устройства. Никаких атак, эксплойтов и подбора паролей. Внешние адреса программа отклоняет.
- Имя устройства: программа спрашивает его у самого устройства (mDNS и NetBIOS - так называют себя компьютеры, Mac, iPhone, принтеры, хранилища) и у роутера своей сети. Вопросы уходят только на найденные адреса своей сети.

**Сеть и трафик** - по кнопке, только чтение, ничего не отправляет:
- как вы подключены: кабель, Wi-Fi (сеть, защита, сигнал), VPN, тип сети, роутер и DNS;
- скорость сейчас и сколько передано с включения;
- куда уходит трафик: какие программы с какими адресами соединены (имена сайтов - только из кэша DNS этого компьютера, новых запросов нет);
- кто подключается к вам: входящие соединения и порты, открытые для сети;
- кто в вашей сети: устройства, которые компьютер недавно видел, с именами (из кэша DNS и из последнего поиска устройств); новые и со случайным MAC отмечены. Любое устройство можно подписать своим именем - подпись хранится на этом компьютере и привязана к MAC-адресу;
- утечки и опасности: открытый или слабый Wi-Fi, общий доступ и обнаружение в общественных сетях, общие папки, IPv6 мимо VPN, порты вредоносных программ, Tor, программы из временных папок, программы удалённого доступа, входящие из интернета, FTP и Telnet.

**Чек-лист безопасности** - 32 совета простыми словами: вход и учётная запись, Windows и программы, данные и диск, сеть и роутер (зачем нужен сетевой экран, почему гостей и умный дом лучше держать в отдельной сети), Wi-Fi, Bluetooth и флешки, привычки. Что видно из проверки, программа отмечает сама; где есть исправление - кнопка «Сделать автоматически». Остальное отмечается галочкой.

**Роутер** - по кнопке «Проверить роутер» в «Сеть и трафик»: включён ли UPnP и какие порты программы сами открыли через роутер в интернет (удалённый рабочий стол, общие папки и VNC - критично). Внешний адрес и «серый» ли он. Вопросы уходят только роутеру своей сети, программа ничего не открывает и не закрывает.

**Обновление программ** - по кнопке: какие программы устарели (через winget, встроенный в Windows установщик Microsoft) и обновление одной кнопкой - одной программы или всех. Без кнопки программа к каталогу не обращается.

**Страж в реальном времени** (полная версия) - пока работает Адамант, раз в минуту сверяет автозагрузку, службы, задачи планировщика, администраторов, Microsoft Defender, файл hosts и прокси. Новое и подменённое - тревога в окне и в трее через минуту, а не при следующей проверке. Обновления программ и свои изменения Адаманта тревогу не поднимают.

**Тревога** (полная версия) - красная кнопка в боковой панели: одним нажатием отключает компьютер от сети (кабель и Wi-Fi, с разрешением администратора), записывает программы, запущенные за последние 30 минут, и говорит, что делать. «Вернуть сеть» включает обратно ровно те адаптеры, что были выключены.

**Уведомления в Telegram** (полная версия, по умолчанию выключены) - тревоги на телефон через вашего собственного бота: «Пока вас не было», приманки, Страж в реальном времени, «Тревога». Уходит только короткий текст тревоги, без отчётов и файлов.

**Bluetooth** - по кнопке, только слушает: включён ли Bluetooth, сопряжённые устройства, кто рядом (производитель, тип, сила сигнала). Предупреждает об устройствах для атак (Flipper Zero, BadUSB), рассылке поддельных окон «подключить наушники» и метках для поиска вещей рядом. Ничего не подключает и не сопрягает.

**Отчёт** - находки по важности: «Критично», «Важно», «Совет», «Не видно», «В порядке». Печать, PDF и сохранение в HTML.

## Бесплатная и полная версии

**Бесплатно** работает всё, что защищает: проверка ПК и индекс, все находки, исправления кнопкой с откатом, Страж, порты, автозагрузка, расширения браузеров, скачанные файлы, сеть и трафик, роутер, поиск устройств, обновление программ, чек-лист, отчёт. Угрозы бесплатная версия не прячет: если с компьютером сопряжено устройство для атак по Bluetooth, она об этом скажет.

**В полной версии** ещё:
- **Bluetooth** - кто рядом, метки для поиска вещей, рассылка поддельных окон, все сопряжённые устройства;
- **Защита входа** - мастер «Закрыть вход в обход Windows»;
- **Учения** и приманки для шифровальщиков;
- **Пока вас не было** - что происходило, пока компьютер был заблокирован, и фото того, кто ввёл неверный пароль;
- **Страж в реальном времени** - тревога через минуту после важного изменения в системе;
- **Тревога** - отключить компьютер от сети одной кнопкой;
- **Уведомления в Telegram** - тревоги на телефон.

Ключ полной версии вставляется в «Настройки» → «Версия». Он проверяется на этом компьютере, без интернета: ключ подписан автором (Ed25519), программа сверяет подпись со встроенным открытым ключом. Ключи выдаёт автор:

```
node tools/license.js issue --key <закрытый ключ автора> --licensee "Имя владельца ключа" [--expires ГГГГ-ММ-ДД]
```

Закрытый ключ хранится только у автора, вне проекта; в репозиторий и архив он не попадает. С `--expires` удобно выдавать пробный ключ на несколько дней.

## Исправления

Кнопка «Исправить…» показывает, что сейчас, что станет и какими командами. Изменение применяется только после «Применить» и разрешения администратора в окне Windows. Прежние значения сохраняются в `%ProgramData%\Adamant\undo` (доступ только у администраторов). Любое исправление откатывается в разделе «Исправления».

Что исправляется кнопкой: брандмауэр, защита Defender в реальном времени, SMBv1, NLA для RDP или выключение RDP, UAC, служба и политика обновлений, гостевая и встроенная учётные записи администратора, автовход с паролем в реестре, программы в автозагрузке (отключение, как в «Диспетчере задач»), LLMNR, WDigest, автозапуск с флешек, удалённый помощник, список уязвимых драйверов, защита LSA, PowerShell 2.0, PUA, облачная защита, контролируемый доступ к папкам, безопасные правила ASR, подмена специальных возможностей, автоблокировка, блокировка после неверных паролей, Ctrl+Alt+Del перед входом, разрешение PIN для BitLocker.

Что программа не меняет сама, а даёт пошаговую инструкцию: пароль BIOS/UEFI, порядок загрузки, Secure Boot, TPM, BitLocker, пароли учётных записей, обновление прошивки. Ошибка в них может стоить данных или загрузки системы.

## Установка и запуск

- `Adamant-Setup-<версия>.exe` - установщик для скачивания: один файл, показывает лицензию и ставит программу так же, как `Установить Адамант.cmd`. Собирается командой `npm run setup`. Проверить архив внутри, ничего не устанавливая: `Adamant-Setup-<версия>.exe /check`.
- `Установить Адамант.cmd` из дистрибутива - установка для текущего пользователя без прав администратора: `%LOCALAPPDATA%\Programs\Adamant`, ярлыки на рабочем столе и в «Пуске», удаление через «Параметры» → «Приложения». Данные - в `%LOCALAPPDATA%\Adamant`, при удалении остаются.
- Окно - Microsoft Edge (или Chrome) в режиме приложения со своим профилем: без адресной строки и вкладок.
- «Работа в фоне» (в настройках, по умолчанию выключена): значок в трее, проверка раз в сутки только на чтение и с низким приоритетом, уведомление только о новых критичных и важных находках и о тревоге от приманок.
- Node.js встроен (`runtime\node.exe`), ставить его отдельно не нужно.

## Разработка

```
npm start        - запустить из исходников (окно программы)
npm test         - тесты (включая настоящую проверку этого компьютера на чтение)
npm run dist     - дистрибутив dist/Adamant-<версия>-win-x64.zip
npm run icon     - значок windows/adamant.ico, public/favicon.png и public/img/diamond.png из art/icon.png
npm run i18n-missing - строки без английского перевода
```

Картинки сделаны в ChatGPT, исходники лежат в `art/`: `icon.png` (камень, из него собирается значок) и `vault.png` (фон окна - древний свод с кристаллами; в окно идёт сжатая копия `public/img/vault.webp`).

Без внешних зависимостей. Строки интерфейса - по-русски через `T('…')` (окно) и `t()`/`tx()` (сервер), английский словарь - `public/i18n-en.js`. Сценарии PowerShell хранятся в UTF-8 с BOM (`node tools/ps-bom.js`).

Устройство: `server/ps/collect.ps1` и разделы `server/ps/sections/*.ps1` собирают сведения (только чтение) → `server/rules.js` и `rules-*.js` превращают их в находки → `server/score.js` считает индекс, `server/guard.js` сравнивает со слепком системы → окно (`public/app.js`) показывает. Исправления: `server/fixes.js` (описание и проверка) и `server/ps/fix.ps1` (применение и откат с правами администратора).
